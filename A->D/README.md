# A->D 交付说明

这份材料给**写报告 + 做可视化**的同学。数据已经标注、统计完，**不需要再跑代码**，打开文件就能写、就能画。

- 总样本：**6093 条**评论（微博 3665 / 小红书 2428）
- 相关评论：**5827 条**（剔除 266 条与友情无关的）
- 进入态度统计：**5528 条**（自己经历 / 嘉宾关系 / CP / 泛论友情）
- 人工抽检：50 条，一致率 86%，Cohen's κ = **0.805**

## 四、画哪些图、用哪个文件

### 图 1｜总体态度分布（环形图或柱状图）

- 数据：`02_图表/数据交付.xlsx` → `态度分布`，或 `agg_long.csv` 筛选 `dimension=stance` 且 `group=全部`
- 数字：反对和解 **36.3%**、中立 **34.5%**、支持和解 **26.4%**、有条件和解 **2.7%**（n=5528）
- 说明：反对是最大类，但不是压倒性多数；有条件和解只有 2.7%，画图时别把四类做成等宽。

### 图 2｜理由 Top 10（横向条形图）

- 数据：`agg_long.csv`，筛选 `dimension=reason`、`group=全部`，按 `pct` 降序取前 10
- 前三条：强行和好不如各自安好 **15.2%**、双方仍有感情/彼此在意 **13.7%**、和解不是目的/释怀即可 **7.7%**
- 注意：理由是多选，百分比之和大于 100%，图注要写清楚。

### 图 3｜友情观念 Top 10（横向条形图）

- 数据：`agg_long.csv`，筛选 `dimension=value`，按 `pct` 降序
- 前三条：真诚与信任是基础 **18.5%**、需要边界感 **9.5%**、友情有阶段性/会流动 **8.3%**
- 说明：这一题的分母是 5827 条相关评论，不是 5528，图注别写错。

### 图 4｜四期态度趋势（折线图，主图）

- 数据：`02_图表/period_stance_wide.csv`（或直接用 `期数态度折线图.png`）
- 趋势：支持和解 **13.4% → 21.3% → 29.5% → 33.6%**；反对和解 **45.4% → 40.2% → 38.3% → 29.8%**；两条线在第五、六期之间交叉
- 样本量：710 / 1809 / 729 / 2280
- 必须写进图注：**第六期只统计到 11-22**，不是完整一周；各期样本量差异大。

### 图 5｜分平台的期数趋势（两张小折线图，二选一或并列）

- 数据：`02_图表/period_platform_stance.csv`
- 用途：检查“支持率上升”是不是平台构成变化造成的
- 注意：第五期小红书的态度样本只有 31 条（合并前 59 条），那一期的分平台点不要过度解读。

### 图 6｜平台态度对比（分组柱状图）

- 数据：`02_图表/platform_stance.csv`
- 数字：微博 支持 27.5 / 反对 37.2 / 中立 32.8；小红书 支持 24.7 / 反对 34.7 / 中立 37.5
- 卡方：χ²=15.87，df=3，**p=0.0012**，差异显著但幅度只有 3 个百分点左右，别写成“截然不同”。

### 图 7｜平台差异（双向条形图 / diverging bar）

- 数据：`02_图表/platform_reasons.csv`、`platform_values.csv`，用 `lift(百分点)` 排序
- 微博更突出：强行和好不如各自安好（+4.6pp）、好聚好散/体面告别（+5.2pp）
- 小红书更突出：对方没有诚意/假道歉（+3.2pp）、及时止损/自我保护（+2.8pp）、宁缺毋滥（+3.2pp）、不内耗/保护自己（+2.8pp）
- 解读：微博更偏“体面结束、各自安好”，小红书更偏“识别不真诚、保护自己”。

### 可选图 8｜评论对象分布 / 点赞分档

## 五、写报告可以按这个结构

1. **数据与方法**：6093 → 5827 → 5528 的口径；50 条人工抽检，κ=0.805（用 `merge_report.md`）
2. **总体态度**：反对 36.3%、中立 34.5%、支持 26.4%、有条件 2.7%
3. **理由与价值观**：理由第一是“各自安好”，价值观第一是“真诚与信任”
4. **期数趋势**：支持上升、反对下降、第五六期交叉；注明第六期只到 11-22
5. **平台差异**：微博偏“体面告别”，小红书偏“及时止损/识别假道歉”；χ² 显著但幅度不大
6. **引语**：从 `quotes.csv` 选 3–5 条，按态度分组，标注“有网友评论”
7. **局限**：非概率样本、平台构成随期数变化、模型标注误差、仅文本

## 六、必须注意的口径

1. **分母不是 6093**：态度用 5528（相关且可表态），价值观用 5827（全部相关）。不要拿 6093 去除。
2. **理由、价值观是多选**：各项之和大于 100%，图注要写“多选”。
3. **平台别只给合并数**：微博和小红书用户结构不同，至少同时给分平台结果。
4. **期数样本不均**：第一、二、三期 710 条，第四期 1809 条，第五期 729 条，第六期 2280 条；第六期只到 11-22。
5. **平台构成随期数变化**：第五期态度样本微博 698 / 小红书 31；第六期微博 1761 / 小红书 519。整体折线可能混入平台差异，建议配一张分平台图（图 5）。
6. **两套分母别混**：`platform_diff.md` 末尾的 742 / 1990 / 790 / 2571 是合并总数；本说明和图表用的是态度样本 710 / 1809 / 729 / 2280，差值是未表态或不可表态的评论。
7. **引语匿名**：`quotes.csv` 的 `user_code` 是代号，不要去找原账号；`labeled.csv` 里有 `user_id`，**不要外发原始数据**。
8. **结论边界**：这是话题讨论者的态度，不能外推到“全体年轻人”。

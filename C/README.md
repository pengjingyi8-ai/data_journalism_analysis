## 三、采集方法

### 工具

- **联网采集**：使用开源工具 [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)（小红书有请求签名与风控，从零实现签名成本高、易触发验证码）。
- **自己编写**：`crawler.py`（原始 CSV → 规范 raw.csv：字段映射、时间窗过滤、按 `note_id`/`comment_id` 去重、`source_type` 分类、去除链接里的访问令牌）；`clean.py`（去重、去空/纯符号/广告/明显无关内容、jieba 分词、生成质量报告）。
- 登录：小红书二维码扫码，复用本机浏览器登录态。

### 关键词分层

只用"后会友期"一词会召回大量 CP/追星噪声，因此按议题分层：

| 层 | 示例 |
|---|---|
| 议题锚点 | 后会友期 和解 / 绝交 / 断联 / 复合 / 原谅 / 不原谅 / 没必要 |
| 嘉宾 × 议题 | 后会友期 许飞 / 厉娜 / 白小纯 / 青稚 / 马天宇 / 张萌 / 文吉儿 / 王子璇 |
| 泛话题（补友情观） | 朋友绝交 / 该不该和好 / 友情内耗 |
| 节目锚点 | 后会友期（用于找官方/嘉宾账号） |

### 操作过程

1. 先用「后会友期」单词做试点，发现召回的多为 CP/追星/星座帖，评论区偏题；据此改用**议题锚点词**为主力。
2. 按关键词分批采集，每批约 6–14 个词，抓取笔记及其评论（含子回复）。
3. 遇接口限流/验证码时暂停，不强行连续请求；原始抓取结果保留为 CSV。
4. `crawler.py` 转换 → `clean.py` 清洗。

## 四、清洗与筛选

从 3432 条原始评论到 1646 条有效评论：

| 删除项 | 数量 |
|---|---:|
| 空 / 纯符号 / 纯 URL | 200 |
| 广告 / 引流 | 13 |
| 明显无关内容（纯附和「是的/同意/点了」、纯语气词、纯表情、纯@好友、纯笑等零信息量短评论，人工复核） | 1554 |

- **帖子级筛选**：排除纯 磕CP/星座/追星/八卦/攻击等噪声帖。
- **评论级筛选**：导出评论清单按长度升序人工逐条查看，只标记删除**明显无关内容**。
- **未做相关性/立场判断**：一条评论是支持还是反对和解，由 A/D 统一标注，保证两平台口径一致。
- 未按评论长度整体删除；`content` 保留原文；`tokens` 为 jieba 分词。

## 五、字段规范

- `raw.csv`（14 字段）：
  `comment_id,post_id,parent_comment_id,content,create_time,crawl_time,user_id,like_count,reply_count,post_title,post_url,source_type,keyword,platform`
- `processed.csv`（16 字段）：
  `comment_id,post_id,parent_comment_id,platform,content,clean_content,tokens,create_time,crawl_time,user_id,like_count,reply_count,post_title,post_url,source_type,keyword`

## 六、合规与隐私

- 小红书二维码登录，不采集私信、手机号、真实姓名等个人信息；
- `user_id` 为 MediaCrawler 脱敏后的 `creator_hash`，不含原始用户 ID；
- `post_url` 已去除访问令牌；
- 控制采集频率，遇验证码人工通过，不做验证码破解、不挂代理池；
- 数据仅用于课程研究，不公开、不商用。

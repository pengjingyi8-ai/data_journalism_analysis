## 三、清洗说明

从 3432 条原始评论到 1646 条有效评论，删除的评论统一归为「明显无关内容」：

| 删除项 | 数量 |
|---|---:|
| 空 / 纯符号 / 纯 URL | 200 |
| 广告 / 引流 | 13 |
| 明显无关内容（人工排除：纯附和「是的/同意/点了」、纯语气词、纯表情、纯@好友、纯笑等零信息量短评论） | 1554 |

- **未按评论长度整体删除**；保留否定词、程度副词、表情。
- **未做主题相关性 / 立场过滤**——相关性、和解态度、立场编码由 A/D 统一标注。
- `content` 保留原文未覆盖；`clean_content` 仅清理符号/URL/@/空白；`tokens` 为 jieba 分词。
- 删除清单可复现：`docs/exclude_comments.txt`（按 comment_id）。
